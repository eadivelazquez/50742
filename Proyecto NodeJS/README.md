# Proyecto Analizador - Legajo 50742

## Requisitos
- Node.js (v18 o superior)
- Java (para el generador de ANTLR)

## Instrucciones de ejecución
1. Clonar el repositorio.
2. Ejecutar `npm install` para instalar la librería de ANTLR4.
3. Para procesar el archivo de entrada: `node main.js`

El programa mostrará la tabla de lexemas-tokens, el árbol sintáctico y ejecutará las instrucciones encontradas.
