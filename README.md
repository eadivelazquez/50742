# Analizador Sintáctico - Legajo 50742

## Descripción
Este proyecto es un analizador léxico, sintáctico e intérprete desarrollado con ANTLR4 y JavaScript para el lenguaje especificado en la cátedra.

## Estructura
La carpeta `Proyecto NodeJS` contiene:
- `Lenguaje.g4`: Gramática asignada.
- `index.js`: Punto de entrada del programa.
- `CustomVisitor.js`: Lógica del intérprete.
- Archivos `input_...txt`: Ejemplos de prueba requeridos.

## Cómo ejecutar
1. Entrar a la carpeta: `cd "Proyecto NodeJS"`
2. Instalar dependencias: `npm install`
3. Ejecutar: `node index.js`
